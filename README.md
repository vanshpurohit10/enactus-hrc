# Enactus H.R. College

The website of Enactus H.R. College, the Enactus chapter of H.R. College of Commerce & Economics, Mumbai, with its two projects: Project Inaayat and Project Sanchay.

Live: https://vanshpurohit10.github.io/enactus-hrc/

- `index.html`: the chapter home page
- `inaayat.html`: Project Inaayat
- `sanchay.html`: Project Sanchay
- `assets/`: shared styles and motion (`enactus.css`, `enactus.js`), photos and logos
- `video/`: a motion video of the whole site, made with Remotion (see `video/README.md`)

It is a plain static site: open `index.html` in a browser, or serve the folder with any static server.
